Ce que tu dois revoir et améliorer: 

1. Sois plus précise sur le code HTML
   Même si tu décris la structure globale (4 divs, 1 bouton…), pense à insérer un extrait de ton code HTML. Par exemple :
   <form method="POST">
       <input type="text" name="titre" placeholder="Titre de l'article">
       <input type="file" name="image_couverture">
       <textarea id="editor" name="contenu"></textarea>
       <select name="categorie">...</select>
       <button type="submit">Publier</button>
   </form>

2. Expliquer comment TinyMCE est intégré
   Tu peux ajouter une ligne comme :
   <script>tinymce.init({ selector: '#editor' });</script>
   Et expliquer que cela transforme le champ texte en éditeur WYSIWYG (c'est la méthode WhatYouSeeIsWhatYouGet)

3. Côté PHP : détaille le traitement
   Explique ce que fait ton script quand le formulaire est soumis :
   - Vérifie si tous les champs sont remplis
   - Protège les données (htmlspecialchars, vérification d’image, etc.)
   - Utilise PDO avec une requête préparée :
     $stmt = $pdo->prepare("INSERT INTO articles (titre, contenu, image, categorie) VALUES (?, ?, ?, ?)");
     $stmt->execute([$titre, $contenu, $image, $categorie]);

4. Structure SQL de la table articles
   Tu peux indiquer :
   CREATE TABLE articles (
       id INT AUTO_INCREMENT PRIMARY KEY,
       titre VARCHAR(255),
       contenu TEXT,
       image VARCHAR(255),
       categorie VARCHAR(100),
       date_publication DATETIME DEFAULT CURRENT_TIMESTAMP,
       statut ENUM('brouillon', 'publie')
   );

5. Donne un exemple de retour utilisateur
   Tu dis qu’un message vert s’affiche : montre le code de ce message ou décris quand et comment il apparaît.
